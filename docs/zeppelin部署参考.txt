一、环境准备
JDK 安装‌
需安装 JDK 1.8 或更高版本，配置 JAVA_HOME 环境变量（通过 echo $JAVA_HOME 验证）‌

二、安装与配置
‌下载与解压‌

从官网下载二进制包（如 zeppelin-0.10.1-bin-all.tgz）并解压至目标目录

wget https://dlcdn.apache.org/zeppelin/zeppelin-0.12.0/zeppelin-0.12.0.bin-all.tgz  
tar -zxvf zeppelin-0.12.0-bin-all.tgz -C /opt  

‌关键配置文件修改‌

‌端口配置‌

修改 conf/zeppelin-site.xml，设置服务端口（默认 8080）：
xml
Copy Code
<property>  
    <name>zeppelin.server.port</name>  
    <value>8080</value>  
</property>  
若端口冲突，可调整为其他值（如 8888）‌。

‌绑定地址‌

修改 zeppelin.server.addr 为 0.0.0.0，允许远程访问‌。
三、启动与验证
‌启动服务‌

bash
Copy Code
cd /opt/zeppelin-0.12.1-bin-all  
./bin/zeppelin-daemon.sh start  
查看进程状态：./bin/zeppelin-daemon.sh status‌。
‌访问 Web 界面‌

浏览器输入 http://服务器IP:8080，若显示 Zeppelin 首页即部署成功‌。
